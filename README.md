# Совместный редактор

Веб-приложение для совместного редактирования текстовых документов в реальном времени.

## Возможности

- **Реальное время**: Изменения синхронизируются между всеми участниками мгновенно
- **Оптимистичные патчи**: Каждое действие применяется локально и отправляется на сервер
- **Управление сессиями**: Отображение активных пользователей в документе
- **Постоянное хранение**: Документы сохраняются в файловую систему
- **Простой интерфейс**: Минималистичный дизайн без лишних элементов

## Технологии

- **Backend**: Spring Boot 3.5.14, Java 21
- **WebSocket**: STOMP через SockJS для двунаправленной связи
- **Frontend**: Vanilla JS, Bootstrap 5.3.3
- **Сборка**: Maven

## Запуск

### Локально

```bash
./mvnw spring-boot:run
```

### Через Docker

```bash
docker-compose up --build
```

Приложение будет доступно по адресу `http://localhost:8080`.

## Использование

1. Откройте главную страницу — список всех документов
2. Введите имя нового документа и нажмите «Создать»
3. Введите никнейм при первом входе в редактор
4. Начните печатать — изменения будут доступны другим участникам сразу

## Структура проекта

```
src/
├── main/
│   ├── java/com/example/collaborative_editor/
│   │   ├── config/WebSocketConfig.java          # Настройка WebSocket
│   │   ├── controller/                          # REST и страницы
│   │   ├── repository/DocumentFileRepository.java  # Сохранение в файлы
│   │   └── service/                             # Бизнес-логика
│   └── resources/
│       ├── static/                              # Фронтенд (HTML, JS, CSS)
│       └── application.yaml                     # Конфигурация
└── test/
```

## Конфигурация

В `application.yaml` можно изменить путь к хранилищу документов:

```yaml
documents:
  storage-path: documents
```
